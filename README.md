# Wedding Invitation

## Deskripsi

Projek ini adalah sebuah halaman web undangan pernikahan yang interaktif dan menarik. Halaman web ini dilengkapi dengan fitur-fitur seperti pengiriman RSVP, pembuatan acara di Google Calendar, dan pemutaran musik latar.

## Fitur

* **Smooth Scrolling**: Halaman web ini memiliki fitur smooth scrolling yang memungkinkan pengguna untuk melihat konten halaman web dengan mudah.
* **RSVP Form**: Pengguna dapat mengirimkan RSVP mereka melalui form yang tersedia di halaman web.
* **Google Calendar Event Creation**: Pengguna dapat membuat acara di Google Calendar dengan informasi yang sudah diisi sebelumnya.
* **Music Playback**: Halaman web ini memiliki fitur pemutaran musik latar yang dapat diputar secara otomatis ketika pengguna membuka halaman web.
* **Pagination**: Halaman web ini memiliki fitur pagination yang memungkinkan pengguna untuk melihat daftar RSVP yang panjang.

## Teknologi

* **HTML**: Halaman web ini dibangun menggunakan HTML5.
* **CSS**: Halaman web ini menggunakan CSS3 untuk styling dan layout.
* **JavaScript**: Halaman web ini menggunakan JavaScript untuk membuat interaksi dan fitur-fitur yang dinamis.
* **Google Calendar API**: Halaman web ini menggunakan Google Calendar API untuk membuat acara di Google Calendar.

## Instalasi

1. Clone repository ini ke komputer Anda.
2. Buka file `index.html` di browser Anda untuk melihat halaman web.
3. Pastikan Anda memiliki koneksi internet yang stabil untuk menggunakan fitur-fitur yang memerlukan koneksi internet.
